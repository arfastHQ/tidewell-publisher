Tidewell Publisher

Tidewell Publisher is a private, internal tool used by Tidewell Studio to upload and schedule its own videos on its own YouTube channels, including Becoming Resilient.

It is not offered to the public. Only the studio's owner signs in to it, to give it access to the studio's own channels.

It uses the YouTube Data API to upload videos, set their titles, descriptions, thumbnails and release times, add them to the channel's playlists, and read the channel's own list of uploads so that nothing is uploaded twice.
