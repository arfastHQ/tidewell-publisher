Privacy policy

Last updated: 22 October 2026

Tidewell Publisher is an internal tool used only by Tidewell Studio to manage its own YouTube channels. It has no public users.

What it accesses

When the studio's owner signs in with Google, the tool receives permission to manage the studio's YouTube channel through the YouTube Data API. It uses that permission only to upload the studio's own videos and thumbnails, set their details and release times, manage the channel's playlists, and read the channel's list of its own uploads.

What it stores

The sign-in token and a record of which videos have been uploaded are stored privately on the studio's own server. No data from YouTube or Google is sold, shared with third parties, or used for advertising. No information about viewers or other YouTube users is collected.

Google and YouTube

The tool uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy. The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be withdrawn at any time from the Google account's security settings (myaccount.google.com/permissions). The stored token is then deleted from the studio's server.

Contact

Questions about this policy can be sent through the contact details on the Becoming Resilient YouTube channel's About page.
